# 坦克大战 · Tank Battle

一个用原生 HTML + Canvas + JavaScript 实现的经典「坦克大战」（Battle City）网页小游戏，单文件即可运行，无需任何依赖。

## 玩法

- 控制你的坦克，消灭不断出现的敌方坦克
- **保护基地（金色老鹰）**，基地被摧毁则游戏失败
- 摧毁砖墙开道，钢墙无法摧毁，草地可以隐藏坦克
- 每消灭一名敌人 +100 分，清空所有敌人进入下一关

## 操作

| 按键 | 功能 |
| --- | --- |
| 方向键 / WASD | 移动 |
| 空格 | 射击 |
| P | 暂停 / 继续 |
| 回车 / 空格 / 点击 | 开始或重新开始 |

## 运行

直接用浏览器打开 `index.html` 即可，或部署到 GitHub Pages。
